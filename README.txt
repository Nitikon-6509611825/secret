# 💗 Romantic Surprise Website


## วิธีเปิด
1. เปิดไฟล์ `index.html` ด้วย Chrome / Edge / Safari
2. ถ้าต้องการเพลง ให้เอาไฟล์เพลง `.mp3` มาใส่ในโฟลเดอร์นี้
3. เปลี่ยนชื่อเพลงเป็น `music.mp3`
4. เปิด `index.html`

## แก้ข้อความจดหมาย
เปิด `index.html` แล้วแก้ข้อความในส่วน:
`<div class="message">`

## เปลี่ยนรูปด้านหลังจดหมาย
วางไฟล์รูปไว้ในโฟลเดอร์นี้ แล้วแก้ค่า `src="photo.jpg"` ที่แท็ก `<img>` ในส่วน `letter-back` ให้ตรงกับชื่อไฟล์รูป

## แก้ชื่อหัวเว็บ
แก้:
`<h1>ถึงคนพิเศษของฉัน 💗</h1>`

## หมายเหตุเรื่องเพลง
เบราว์เซอร์บางตัวไม่อนุญาต autoplay พร้อมเสียงจนกว่าผู้ใช้จะมี interaction
เว็บจึงพยายามเปิดเพลงตอนเข้า และจะลองเปิดอีกครั้งเมื่อผู้ใช้แตะหน้าจอ
